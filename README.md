# Task 2 - Superstore Sales Analysis

## 📌 Project Overview

This project is part of my Data Analytics Internship - Task 2.

The objective of this task was to analyze Superstore sales data and identify
important business performance insights using Excel, SQL, and Power BI.

## 🛠️ Tools Used

- Microsoft Excel
- MySQL
- Power BI
- SQL
- DAX

## 📊 Excel Analysis

The Excel analysis included:

- Data cleaning and preparation
- KPI calculations
- Sales and profit analysis
- Regional analysis
- Category and region analysis
- Monthly sales and profit trends
- Top 10 customer analysis

## 💻 SQL Analysis

The dataset was divided into two tables:

- Orders
- Customers

SQL analysis included:

- Creating database and tables
- Importing CSV data
- Data validation
- SQL JOINs
- GROUP BY
- Aggregations
- Business KPI queries

### Dataset Size

- Orders: 9,994 records
- Customers: 793 records

## 📈 Power BI Dashboard

The Power BI dashboard includes:

- Total Sales
- Total Profit
- Profit Margin
- Total Customers
- Sales by Region
- Sales by Segment
- Profit by Category
- Monthly Sales Trend
- Top 10 Customers

## 💡 Business Insights

Some key findings from the analysis:

- West is the strongest region by sales.
- Consumer is the largest sales segment.
- Technology is the most profitable category.
- Sales increase significantly toward the latter part of the year.
- South represents an opportunity for further business analysis.
- Furniture requires attention due to comparatively lower profitability.

## 📄 Business Summary

A detailed Business Summary Report has been prepared based on the Excel and Power BI analysis.

## 🎯 Key Learning

This project helped me understand the complete analytics workflow:

Excel → SQL → Power BI → Business Insight
